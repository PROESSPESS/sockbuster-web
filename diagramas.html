Matriz de Requerimientos

Acá dejé resumidos los requerimientos clave del proyecto, separados entre lo que hace la página para el usuario y las metas de rendimiento y seguridad.

Requerimientos Funcionales (RF)

  • RF01 - Catálogo Temático: Filtrado dinámico de productos por colecciones de películas y series.
  • RF02 - Carrito & Checkout: Manejo de compras e integración del código único de pedido (UUID).
  • RF03 - Administración de Inventario: Control de stock, precios y categorías asociadas.
  • RF04 - Gestión de Reseñas: Módulo para que los usuarios dejen calificaciones con estrellas y comentarios.

Requerimientos No Funcionales (RNF)

  • RNF01 - Rendimiento: Página alojada en la nube con un tiempo de carga super rápido (menos de 2 segundos).
  • RNF02 - Seguridad: Protocolo HTTPS activado y validación de sesiones administrativas con tokens JWT.

Vista de Procesos — Diagrama de Secuencia

Acá muestro paso a paso lo que pasa internamente cuando alguien hace checkout: desde que se presiona el botón, la API revisa si hay stock, guarda el pedido en la base de datos y le responde a la pantalla con su ID único.

sequenceDiagram
    autonumber
    actor Cliente
    participant FE as VistaCarrito Frontend
    participant BE as ControladorPedido API
    participant INV as ServicioInventario
    participant DB as BaseDeDatos

    Cliente->>FE: Clic en Checkout
    activate FE
    FE->>BE: POST /api/checkout
    activate BE
    
    BE->>INV: validarStock()
    activate INV
    
    alt Stock Disponible
        INV-->>BE: Confirmacion OK
        BE->>DB: guardarPedido()
        activate DB
        DB-->>BE: PedidoGuardado (idPedido UUID)
        deactivate DB
        BE->>INV: descontarStock()
        BE-->>FE: 201 Created (idPedido)
        FE-->>Cliente: Muestra confirmacion e ID Unico
    else Stock Insuficiente
        INV-->>BE: Error Stock Insuficiente
        deactivate INV
        BE-->>FE: 400 Bad Request
        FE-->>Cliente: Notifica Sin Stock Suficiente
    end
    
    deactivate BE
    deactivate FE
